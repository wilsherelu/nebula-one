# 模板核算界面修订与自定义编辑修复

用户提供的两张截图显示了真实产品问题：模板新建自定义方案后，规则编辑器调用项目填报接口，遇到 `PROJECT_TEMPLATE_UNAVAILABLE` 就无法编辑；同时模板列表和编辑器的按钮、导航及说明堆叠。此前验收没有覆盖“模板中新建空白方案→真实编辑器”这一整链，不能将旧结论当作该路径已经通过。

## 修复

模板聚合接口现在返回精确来源版本的模型展示图，编辑器直接从图列出过程和全部流，不要求源应用具备填报绑定。已有身份、版本、内容哈希及规则校验保持原合同，没有放宽项目填报守卫。名称使用现有版本化展示资源和精确目录，不在前端按名称猜测翻译。该图只用于展示和逐流选择，不回写模型；保存仍发送过程/交换身份与规则。

列表页改为 CBAM、范围1–3两张等宽卡片，方案选择和操作对齐，长说明折叠。自定义方案在下方独立列表中编辑或新建。PCF仍为模型默认LCIA，不进入规则卡片。

进入编辑器后隐藏模板的外层导航和项目操作，保留返回、规则名称、分类建议和保存；版本与复制折叠。过程在左、流在右，是否计入和结果分类同一行编辑，来源按需展开。流类型和背景状态缩成短标签，完整含义可查看。修复390px下模板标题的粘性定位压住编辑器的问题。
