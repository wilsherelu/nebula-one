# Steel template and result boundaries

The released example is the blast furnace–basic oxygen furnace crude-steel model under `cases/standard-lca-seeds/iron-steel-bf-bof-crude-steel/`. Its `seed.json` pins the graph, roles, authored flows, boundaries, method package, and expected values by content hash. The public catalog exposes this template and the small electricity supply example; it does not expose hydrogen or ammonia models.

The steel graph owns fourteen product Flow rows. Its fossil CO2 elementary Flow and the electricity supply's TianGong Flow versions are imported and verified through Nebula LCA's public Flow APIs. Two older product Flow identities used by the steel graph originated in a separately authored seed. The public resource `src/nebula_one/resources/steel_catalog/steel-flow-prerequisites.v1.zip` contains exactly those two catalog rows, without that seed's project or model. Its adjacent JSON descriptor records the original source seed, version, source bundle hash, selected Flow UUIDs, and resource hashes. Startup calls `POST /api/native-project-bundles/import-catalog-flows` only for the selected rows, then re-reads their catalog identities. A different destination row fails closed. The steel model's original bundle hash remains unchanged.

The four application views consume a frozen solve tied to an exact data revision. MFA reports its mass-flow conservation evidence. Product climate may show linked background contributions only when the selected Nebula LCA solve carries exact background and indicator receipts; a foreground-only answer is partial. CBAM is a versioned rule trial with explicit boundary and reporting period, not a declaration. Organizational lifecycle grouping separates on-site direct emissions, purchased secondary energy, and other selected value-chain activities; missing supplier factors remain missing. None of these views substitutes an absent factor with zero or promotes a partial result to a complete footprint.

For real use, check the seed's source citations, model assumptions, missing coverage, and reporting boundaries against the facility's measured data. Commercial LCI providers, method vectors, and local result databases are intentionally absent from this repository. Connect authorized provider data to Nebula LCA separately and retain exact provider release and content hashes with every solve.
