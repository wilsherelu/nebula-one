# 钢铁模板的核算口径

本说明适用于当前内置高炉—转炉钢铁模板。原始种子1.1.0保留供历史回放，其中的条款解释以本说明及项目冻结的核算方案为准。数值清单是声明的示例，不是钢厂实测清单。

## 自定义范围1–3

沿用产品既有生命周期归集设计：范围1表示纳入的现场过程贡献，范围2可以包含所购电力、热、蒸汽等供应路径的生命周期贡献，范围3归集其他供应链贡献。用户按过程、流和消费路径调整纳入边界及归组。排除量保留在明细中，同一贡献只计一次，缺数据不能当零。

这是所选自定义方法的定义。只有明确选择GHG Protocol对照方案时，才按其发电环节口径检查范围2；不会用该对照方案限制生命周期方法。结果与导出应保留实际采用的方案及版本。

## CBAM试算

六条示例直接CO₂合计为1940.739734 kg／1000 kg粗钢，表示已建模的直接分项。它不等于完整、经核证的CBAM嵌入排放。

原始 `boundaries/cbam.json` 和 `acceptance/expected-values.json` 中以下解释已过时：

| 旧解释 | 当前解释 |
| --- | --- |
| 钢铁只计直接排放，因此所有购电都排除 | 最终钢铁的直接排放口径不排除烧结矿前体的适用间接排放；烧结600 MJ单列，连铸25 MJ按最终产品口径处理 |
| 在同一图内的烧结和铁水不是前体 | 内部转移仍需正确识别；联合监测需要设施和用途证据，不能只凭图结构判定 |
| 煤气外送等未建模时可称保守上界 | 遗漏影响的净方向尚不确定，不称上界；保留废气、发电/供热归属和净化排放缺项 |
| BF-BOF路线一律禁止电极端口 | 以实际工艺和来源流为准；路线名称不能代替是否使用电极的证据 |

当前CBAM复核方案1.0.7已表达这些限制。烧结电力缺合格因子、联合监测或废气证据未闭合时，完整值保持不可得。用户可复制方案探索不同边界，探索结果仍使用自定义方案身份。

依据与独立复算见[2026-10-15来源核验](acceptance/TEMPLATE_SOURCE_REVIEW_20261015.md)，其中链接欧委会2026钢铁及计算方法指导。旧冻结资产不原位改写，新方案不会修改既有项目的结果。

## 本轮验证

方案集1.1.6沿用生命周期方法1.0.10；GHG对照方法1.0.6补齐两处购电声明。1.1.5方案集原字节归档在 `resources/template_method_libraries/archive/`，不参与新项目默认选择。

66项定向后端回归通过，覆盖方法复制、精确引用、历史方案集、组织归集和网络消费路径。隔离One 19048 / LCA 19041的真实HTTP验证18项通过，证据 `.local-evidence/library-116-lifecycle-preserved/summary.json` 记录被测源码SHA256。生命周期范围1为1940.7397340000002、购电范围2为98.67998645833333 kg CO₂-Eq，包含烧结和连铸；复制方案数值相等，逐流排除只移动对应贡献，原记录哈希不变。GHG对照复制覆盖两处购电，跨基础方案误用仍拒绝。

该验证使用已有公开电力清单，非现场完整企业排放核证。本轮未修改前端、未重建安装包、未重跑全量后端；隔离服务验收后停止，用户6616未改动。
